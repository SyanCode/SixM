# SixM

**Независимый от игры** фреймворк для мультиплеера и модов в духе FiveM, рассчитанный на GTA VI для ПК и проекты портирования. Весь код оригинальный.

## Состояние (v0.1)

| Компонент | Статус |
|---|---|
| Выделенный сервер (WebSocket, тики, снапшоты, ограничение частоты) | ✅ |
| Система ресурсов (`resource.json`, start/stop/restart, серверные и клиентские скрипты) | ✅ |
| API скриптов (`sixm.on`, `onNet`, `emitClient`, `emitAllClients`, `getPlayers`, `kick`) | ✅ |
| Эталонный клиент + имитационный адаптер + тестовый бот | ✅ |
| **Адаптер для реальной игры** (`GameAdapter`) | ⛔ предстоит написать, см. ниже |

## Быстрый старт

```bash
npm install
npm start          # сервер на ws://localhost:30120
npm run bot        # (другой терминал) бот, который двигается и пишет в чат
npm test
```

Консоль сервера: `start|stop|restart <ресурс>`, `players`, `resources`, `quit`.

## Чего SixM не делает (и почему)

- **У GTA VI нет официальной версии для ПК и поддержки модов**, поэтому легитимной точки подключения пока нет. `client/adapter.js` задаёт контракт, который нужно реализовать, когда она появится (официальный API или проект портирования, явно разрешающий плагины).
- Репозиторий **не содержит и не будет содержать** код, ассеты и бинарные файлы Rockstar, утечки и пиратские сборки. Не добавляйте их.
- Скрипты изолируются через `node:vm`, что **не является** песочницей безопасности: запускайте только доверенные ресурсы.

См. [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) и [docs/PROTOCOL.md](docs/PROTOCOL.md).
